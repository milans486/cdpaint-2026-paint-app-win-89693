## About CDPaint

CDPaint is designed for artists and developers who want a familiar, straightforward pixel-editing workflow without losing access to tools that matter for retro-style production. Its interface follows an MS Paint-inspired approach, making it approachable for quick edits, sprite work, and indexed art tasks.

It is especially useful for people building assets for classic handheld projects, ROM hacking workflows, and other low-color art pipelines. With support across both web and desktop environments, CDPaint gives you a flexible way to create, edit, and export pixel art wherever your work happens.

## Usage

Start by creating or importing pixel art, then choose the workflow that fits your project:

- Use the drawing tools for direct pixel placement and MS Paint-style editing
- Adjust indexed colors in the palette editor when working with limited-color assets
- Split sprite sheets into smaller pieces before exporting or organizing assets
- Use selection tools to move, edit, or isolate sections of your artwork
- Switch on tiled drawing mode when building repeating patterns or grid-based assets
- Assign custom hotkeys to speed up repetitive editing tasks
- Export assets using the retro and GBA-oriented output tools when preparing game content

For best results, keep your palette and export targets aligned with the format you need before finishing a project.
